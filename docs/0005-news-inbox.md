# 짧게 보관하는 뉴스·기관소식 Inbox

결정:

- 한국경제·매일경제와 한국부동산원·신용보증기금·한국가스공사의 공식 목록에서 제목·원문 URL·출처·분류·게시일시·최초 수집시각만 수집한다. 본문·첨부파일·요약·추천·북마크는 저장하지 않는다.
- 뉴스는 HTTP와 BeautifulSoup 및 출처별 파서를 사용한다. 신문은 분야별 최신 목록을, 기관은 최근 30일 경계까지 최대 10페이지를 수집한다. 신문 7일 전체를 처음부터 역수집하지 않는다.
- 매일경제의 날짜 누락은 실행당 최대 100개 공식 기사 페이지의 공개 날짜 메타데이터로만 보강한다. 확인할 수 없는 날짜는 최초 수집일로 대체하며 기사 URL 숫자로 날짜를 추측하지 않는다.
- URL의 추적 파라미터는 제거하고 기관 게시물 ID 등 의미 있는 query는 보존한다. 정규화 URL로 중복을 막고 구체 분야가 주요뉴스보다 우선한다. 제목 유사도로 중복을 판정하지 않는다.
- 서울 달력 날짜로 오늘을 포함해 신문 7일·기관 30일만 보관하며 미래·기간 밖 항목은 저장하지 않는다. 게시일이 없으면 최초 수집일을 쓴다.
- `처리 완료`는 한 트랜잭션에서 항목을 삭제하고 원래 TTL 경계까지만 재수집을 억제한다. 억제가 끝나도 유효 보관 기간을 벗어난 항목은 저장하지 않는다. 영구 뉴스 차단이나 추가 읽음 상태는 두지 않는다.
- 신문 분류는 정치·경제·사회·IT·세계·주요뉴스로 통일한다. 기관은 보도자료가 기본이며 한국부동산원의 명백한 정기 조사·동향만 정기 통계로 분류한다.

이유: 취업 준비에 필요한 최신 제목과 출처를 빠르게 확인하는 개인용 Inbox에 집중하고, 요청량·저장량과 기존 채용 기능에 미치는 영향을 제한하기 위해서다.
