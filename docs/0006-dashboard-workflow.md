# 사용자 검토 흐름과 반응형 화면

결정:

- 공고 상태는 검토 대기·지원 예정·지원 완료·제외의 네 가지다. 새로 수집한 공고는 검토 대기의 NEW로 시작한다. 확인 또는 상태 변경으로 NEW를 해제하고 원문 링크 열기는 확인으로 간주하지 않는다.
- 핀은 지원 예정에서만 유지되는 사용자 상태다. 목록은 기관 필터+핀 → 기관 필터 → 핀 → 일반 순이며 각 핀 그룹은 마감일순으로 표시한다. 지원 예정에서 벗어나면 핀을 해제한다.
- 채용은 진행 중·보관함 묶음을 유지하며 1,400px 이상에서는 선택 묶음의 두 목록을 나란히, 좁은 화면에서는 선택 상태 하나만 표시한다. 제외 직후 실행 취소를 제공한다.
- 채용·뉴스 화면은 같은 페이지에서 전환하되 뉴스 JavaScript·CSS와 수집 진행 상태를 분리한다. 새 페이지는 채용 화면으로 시작한다.
- 뉴스는 기간·자료 종류·출처·분류·제목 필터와 실제 결과 건수를 제공한다. 자료 종류는 전체가 기본이며 출처·분류의 복수 선택은 브라우저에 보존한다. 원문은 새 탭으로 열고 처리 완료 성공 후 목록에서 제거한다.

이유: 사용자가 직접 내린 상태와 읽기 동작을 구분하고, 넓은 화면과 좁은 화면 모두에서 빠르게 공고·소식을 검토할 수 있게 하기 위해서다.
