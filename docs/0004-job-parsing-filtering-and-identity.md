# 구조화된 공고 판정

결정:

- 원본 제목·마감 문구를 보존하고 제목·날짜·필터 파서는 순수 함수로 분리한다. 파싱 실패 시 추측하지 않고 원문으로 표시한다. 마감은 날짜형·상시·미확인으로 나눈다.
- 기관 키워드는 파싱된 기관명에, IT 키워드는 파싱된 직무에만 대소문자 무시 부분 일치로 적용한다. 두 키워드 목록은 웹에서 편집해 SQLite에 저장하고 재수집 없이 적용한다.
- 대상 기관은 직무와 무관하게 표시한다. 일반 기관은 IT 직무가 일치할 때만 표시하고 일치한 직무만 보여 준다. 직무 파싱 실패 시 대상 기관은 원문으로 표시하고 일반 기관은 제외한다.
- 채용 링크는 `?` 이후를 제거한 URL로 저장·비교해 수집 조기 종료와 중복 판정에 사용한다.
- 다른 링크여도 파싱된 기관·고용 형태·직무 목록·마감 유형과 날짜가 같으면 추가하지 않는다. 미확인 마감은 원문도 같아야 중복으로 본다. 뉴스 URL에는 채용용 query 제거 규칙을 적용하지 않는다.

이유: 필터의 오탐과 추적 파라미터·다른 링크로 생기는 중복 공고를 줄이면서, 불확실한 원문 정보를 잃지 않기 위해서다.
